# 三角形ABCの通過立体の可視化（2026兵庫県立大学・社会情報科学）

パラメータ $t$ によって位置が変わる三角形 ABC が、$-\frac{\pi}{2} \le t \le \frac{\pi}{2}$ の範囲で動いたときに通過してできる立体を、ブラウザ上で3D表示するWebアプリです。

## 頂点の定義

$$
\begin{aligned}
A &= \left(\cos^2 t,\ \sin t\cos t,\ t\right)\\
B &= \left(\left(-\tfrac{\sqrt3}{2}\sin t-\tfrac12\cos t\right)\cos t,\ \left(-\tfrac12\sin t+\tfrac{\sqrt3}{2}\cos t\right)\cos t,\ t\right)\\
C &= \left(\left(\tfrac{\sqrt3}{2}\sin t-\tfrac12\cos t\right)\cos t,\ \left(-\tfrac12\sin t-\tfrac{\sqrt3}{2}\cos t\right)\cos t,\ t\right)
\end{aligned}
$$

## 図形の性質

3点はどれも平面 $z=t$ 上にあります。$R_\theta$ を $z$ 軸まわりの回転とすると、xy成分は次のように書けます。

$$
A_{xy} = \cos t\,(\cos t,\ \sin t),\qquad B = R_{120^\circ}A,\qquad C = R_{240^\circ}A
$$

- 各断面は、中心が $z$ 軸上にあり外接円の半径が $\cos t$ の正三角形です。$t$ が増えると回転します。
- $t = \pm\frac{\pi}{2}$ では三角形が1点につぶれます。そのため立体は、点 $\left(0,0,\pm\frac{\pi}{2}\right)$ が先端になった紡錘形の閉じた立体になります。
- 点 A のxy座標は円 $\left(x-\frac12\right)^2+y^2=\frac14$ をちょうど1周します。

### 断面積と体積

$$
S(t)=\frac{3\sqrt3}{4}\cos^2 t
$$

$$
V=\int_{-\pi/2}^{\pi/2}\frac{3\sqrt3}{4}\cos^2 t\,dt=\frac{3\sqrt3}{8}\pi\approx 2.0405
$$

## 使い方

1. `index.html` をブラウザで開きます(ダブルクリックで開けます)。
2. Three.js と KaTeX をCDNから読み込むため、インターネット接続が必要です。

ブラウザの設定などでローカルファイルから正しく表示されない場合は、簡易サーバーを使って開いてください。

```bash
# Python 3 の場合
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## 画面の操作

### マウス

| 操作 | 動作 |
|---|---|
| 左ドラッグ | 視点の回転 |
| ホイール | ズーム |
| 右ドラッグ | 平行移動 |

### コントロールパネル

| 項目 | 内容 |
|---|---|
| $t$ スライダー | $t$ の値を変え、そのときの三角形(黄色)と頂点 A(赤)・B(緑)・C(青)を表示 |
| 再生 / 停止 | $t$ を自動で動かすアニメーション |
| 視点リセット | カメラを初期位置に戻す |
| 速度 | 再生速度 |
| z方向の縮尺 | 立体を $z$ 方向に伸縮して表示(初期値 0.8) |
| 立体の不透明度 | 側面の透明度 |
| 立体(側面)を表示 | 3辺が掃く曲面の表示切り替え |
| 現在のtまでの通過部分のみ表示 | 立体が下から作られていく様子を表示 |
| ワイヤーフレーム | 側面をメッシュ表示 |
| 頂点A,B,Cの軌跡 | 各頂点が描く空間曲線を表示 |
| 断面の三角形を重ねて表示 | 一定間隔の断面三角形を表示 |
| 座標軸 | 軸・矢印・ラベル($x,y,z$、目盛り)の表示切り替え |

パネル下部には、現在の頂点座標、外接円半径 $r=\cos t$、断面積 $S(t)$、体積 $V$ が数式つきで表示されます。

## 立体の色

側面は $t$ の値に対応した虹色で塗られています。$t=-\frac{\pi}{2}$ が赤、$t$ が増えるにつれて黄・緑・青・紫と変わります。

## 使用技術

| ライブラリ | 用途 |

Import Maps を使っているため、Chrome / Edge 89 以降、Firefox 108 以降、Safari 16.4 以降が必要です。

## カスタマイズ

`index.html` 内の次の定数を変えると、表示を調整できます。

| 定数 | 意味 | 初期値 |
|---|---|---|
| `T0`, `T1` | $t$ の範囲 | `-PI/2`, `PI/2` |
| `NT` | $t$ 方向の分割数(曲面の滑らかさ) | `400` |
| `NS` | 辺方向の分割数 | `24` |
| `defaultCam` | カメラの初期位置 | `(3.5, 2.8, 2.0)` |

`T0`, `T1` を変えると、スライダーの範囲(HTMLの `min` / `max` 属性)も合わせて変更してください。範囲の端で三角形が点につぶれない場合は、上下のふた(端の断面の三角形)を追加しないと立体が閉じません。また、パネルの体積表示は $-\frac{\pi}{2}\le t\le\frac{\pi}{2}$ の場合の値なので、範囲を変えたときは書き換えが必要です。
